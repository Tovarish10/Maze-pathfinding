# **课程实验报告**

### **探测迷宫通路**

</div>

---

## 一、实验目的

- 理解迷宫路径搜索问题的基本建模方法。
- 掌握深度优先搜索（DFS）与广度优先搜索（BFS）的实现思路。
- 熟悉栈、队列、字典等数据结构在图搜索中的应用。
- 通过实验比较不同搜索策略在路径输出与搜索结果上的差异。

## 二、实验任务

1. 设计二维迷宫的数据表示方式，用于区分通路与障碍。
2. 实现从入口到出口的路径搜索功能。
3. 支持输出单条路径与所有可行路径。
4. 将最终路径以坐标序列形式输出，并在控制台中可视化渲染。

## 三、实验原理

迷宫可以抽象为一个二维网格图：

- `0` 表示可通行区域；
- `1` 表示障碍区域；
- 默认入口为 `(1, 1)`；
- 默认出口为迷宫右下角`graph::dst`。

本实验主要采用以下两类搜索方法：

### 1. 深度优先搜索（DFS）
DFS 会沿着某一方向不断深入，直到无法继续前进，再逐步回溯。该方法适合寻找一条可行路径，也可通过记录状态枚举多条路径。

### 2. 广度优先搜索（BFS）
BFS 按层扩展搜索节点，首次到达出口时往往可以得到较短路径。通过维护前驱节点 `prev`，可以从终点反向回溯得到完整路径。


## 四、实验方法与步骤

### 1. 迷宫建模
使用二维数组表示迷宫地图，其中每个元素对应一个位置的状态。程序中通过封装的 `maze` 与 `point` 类型进行访问与坐标管理，从而简化路径搜索过程。

### 2. 路径搜索实现
- **DFS 递归版**：
>> 每个递归函数持有目前检索到的节点，若是终点，则返回/弹出到上一个未检索分支，否则，检测并遍历所有下一步路径。
>>
>> 由于每个递归函数需要共享图和探索路径，故使用类封装这些函数，最后用`get_ans()`得到结果。
- **DFS 显式栈版**：与递归版类似，但是使用显式栈模拟递归过程。
- **BFS**：
>> 使用队列来处理节点，出队一个元素，侦测它并把它的相邻节点入队，并把它的前驱节点存入字典
>>
>> 若出队元素即为终点，则开始迭代访问字典直到找到起点

### 3. 搜索规则
每次从当前节点按照固定顺序向四个方向扩展：右、下、左、上。若节点越界、为障碍或已经访问过，则重置为`(0,0)`，最终`detect_base()`返回一个四元素的数组。

### 4. 结果输出
返回一个`std::vector<point>`，如果结果存在，里面保存着所有节点，否则，只有起始节点<br>
程序将搜索得到的路径按坐标序列输出，并调用 `os<<route(maze,std::vector<point>)` 在终端中显示迷宫通路，便于直观观察搜索结果。

### 5. 实验验证
在给定测试迷宫上运行程序，验证是否能够成功找到从入口到出口的通路，并对不同算法的输出结果进行比较。

## 五、实验结果

程序能够正确识别迷宫中的可行通路，并输出对应的路径坐标。对于当前测试数据：

- DFS 比较通用，适合寻找可行路径，但更擅长找到所有简单路径；
- BFS 更适合用于寻找较短路径，找到所有路径实现困难且复杂度大；
- 显式栈与递归实现的 DFS 在思想上等价，但实现形式不同。
